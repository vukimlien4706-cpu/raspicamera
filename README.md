**Raspberry Pi 4 Camera Project with MediaPipe**

Before using this library, be warned that the actual image (output.jpg) is taken from the Raspberry Pi Camera Module V2 using picamera2 API (see NOTICE.txt for details).
As such, trying to get this to work with NVIDIA Jetson would be confusing and requires special treatment.

Cloning with Git outside of supported hardware would likely get you nowhere. Sorry about that.
